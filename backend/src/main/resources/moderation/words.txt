#
# ⚠️ 这是**占位词库**，不是可用的风控词表。它的作用是让审核链路有真实数据流过、
# 并把「命中后拒绝」的行为钉在契约测试里；上线前必须替换成完整的词库。
#
# 规则（见 DefaultTextModeration）：
#   - 每行一个词，读取时做 NFKC 归一 + 转小写 + 压缩连续重复字符
#   - 长度 <2 的词会被**丢弃**：中文单字词（"钱"、"赌"）误伤率极高，
#     宁可漏拦也不要把正常笔记全拦下来
#   - 匹配方式是子串包含，不是分词后精确匹配 —— 换句话说一个词条会拦下
#     任何包含它的文本，选词时要选**组合特征明显**的短语
#
# 下面这几条都是刻意挑的「组合起来才违规」的短语，单看任一条都不至于误伤：
